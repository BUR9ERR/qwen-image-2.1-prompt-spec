# Qwen-Image-2.1 提示词规范

把 Qwen-Image-2.1 官方仓库里的**提示词改写模型系统提示词**，整理成一套可直接执行的规则集，覆盖文生图、图像编辑、角色卡、多视图 / 三视图、动作变更（含双图姿态迁移）。

目标不是再写一份教程，而是让任意 LLM 拿到这套规则后，能稳定产出 Qwen-Image-2.1 可直接渲染的提示词。

## 为什么以官方 prompt 为准

网上关于 Qwen-Image-2.1 提示词的教程大多是二手总结。真正的规范在仓库的 `prompt_rewrite/prompts/` 下：

- `system_prompt_t2i.txt`（约 10 KB）
- `system_prompt_edit.txt`（约 18 KB）

这两份是指令微调模型（Qwen3.5-VL 9B）**训练时使用的系统提示词**，等于官方对"什么算合格提示词"的精确定义。主 `README.md` 里唯一的明确模板只有透明底 RGBA 一句：

```
This is an RGBA image with transparency. <description>. The image has alpha channel and the background is transparent.
```

其余结构、语态、比例、文字规则，全部来自上述两份系统提示词。

## 文件说明

| 文件 | 读者 | 内容 | 篇幅 |
|---|---|---|---|
| `Qwen-Image-2.1-提示词规范.md` | 人 | 完整规范 + 依据 + 示例 + 差异矩阵 + 反模式 + 自检清单 | 约 2.2 万字 |
| `Qwen-Image-2.1-提示词规范-投喂版.md` | 模型 | 可直接作为 system prompt 的指令集 | 约 0.8 万字 |

**普通版**是给人读的说明书：带官方来源、`[官方]` / `[推导]` 标注、讲支配原则与失败模式、含完整长示例。
**投喂版**是给模型执行的指令：删去来源与推演，改为命令式语态、硬性禁令、字段互斥的机械约束。

两者规则一致，投喂版是普通版的可执行子集。**改规则先改普通版，再同步投喂版。**

## 覆盖场景

| 场景 | 骨架 | 关键约束 |
|---|---|---|
| 文生图 | 观察式八步 | 约 20 句 / 400–500 词，位置短语 8–14 个触四角，零质量词 |
| 图像编辑 | 指令式六槽 | 属性解耦，只改点名属性并推到强可辨，其余锁输入保真 |
| 角色卡 | 观察式 / 指令式 | 外观锚点只定义一次，后续回指；标签 ≤4–6 条 |
| 三视图 | 观察式 / 指令式 | 等基线等比例无透视；比例按"单格形状 × 宫格数"自适应 |
| 动作变更 | 指令式 | 姿态点到关节级，其余全部锁定；双图时分配身份源 / 姿态源 |

带参考图时，角色卡与多视图会从"设计"变成"重构"：语态切指令式、身份改用 `<imageN>` 指图、输出契约变三字段。

## 六条最容易踩的规则

1. **两种语态不能混**——文生图是"报告画面里有什么"，编辑是"下达要做什么"。
2. **比例只进字段**——正文出现 `16:9`、`2048`、`2K` 一律不合格；2K/4K/8K 是质量词，不是比例依据。
3. **多图必须 `<image1>`**——禁止"第一张图 / the first image"，单图反而禁止用标签。
4. **双语言决策**——引号外的描述语种跟指令（中文→中文，其他→英文）；引号内要渲染的文字有独立三级优先级，图中已有文字时用图中主导语言。
5. **三视图别套 3:1**——站姿人物横排三视图应算成 `1:1`，拉宽会把每格竖构图压扁；只有横向主体（如汽车）才用 `3:1`。
6. **保留条款锁内容、不锁强度**——编辑时越具体描述"要保留的东西"，它越容易漂移。

## 用法

**做 agent / 固定工作流 / 批量出提示词** → 用投喂版，直接作为 system prompt，省约 65% token。

**查依据 / 改规则 / 向他人解释** → 用普通版。

**只要写一条提示词** → 两者都能贴；投喂版输出干净，普通版会带出说明腔。

## 输出契约

无图场景（两字段）：

```json
{"rewritten_prompt": "<英文描述，单段>", "wh_ratio": "3:2"}
```

有图场景（三字段，后两个互斥，有且只有一个带值）：

```json
{"rewritten_prompt": "<编辑指令，单段无换行>", "wh_ratio": "", "ratio_follow": "<image1>"}
```

## 标注说明

文中 `[官方]` 表示原文可查；`[推导]` 表示由官方规则组合所得，官方无独立章节。

- **官方可查**：文生图八步规范、编辑改写规范、双语言决策、画幅映射表、三视图与多宫格的比例自适应算法、RGBA 模板。
- **推导**：角色卡、动作变更、双图姿态迁移。其中姿态迁移官方画布表里没有对应行，属能力边界外的规则补充，文中已说明理由。
